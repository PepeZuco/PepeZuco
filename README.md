## 🚀 Featured projects

### 🎧 Rig: an AI music friend for Spotify
A personal web service that finds songs with you in a chat, organizes playlists and keeps a history of your library.
FastAPI on Railway, a Claude tool loop with strict cost ceilings, every suggested song verified against Spotify,
a daily library sync with change tracking, and Austin, an animated cat mascot drawn in code.
→ [Write-up and screenshots](https://github.com/PepeZuco/rig-showcase) *(the source is private)*

### 💿 Vinyl Collection
A Flask + SQLAlchemy app for cataloguing my record collection: cover art, genres, pricing and Spotify sync, with a test suite.
→ [Live demo](https://vinyl-collection-zucoloto.up.railway.app/) · [Code](https://github.com/PepeZuco/vinyl-collection)

### 💬 Chat Analyzer
Upload a WhatsApp export and get charts of who talks, when and how. Parsed in memory, so nothing is stored.
→ [Live demo](https://whatsappparser-production.up.railway.app/) · [Code](https://github.com/PepeZuco/whatsapp_parser)

### 🚗 Uber trip duration prediction
Data cleaning, EDA and an ML pipeline that predicts ride durations in São Paulo.
→ [Code](https://github.com/PepeZuco/uber_assessment)
